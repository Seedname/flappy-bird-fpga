# Flappy Bird FPGA

This is a Flappy Bird Clone implemented in SystemVerilog on an DE10-Lite FPGA. [Youtube link if video doesn't load.](https://www.youtube.com/watch?v=ogqy43zKX7U)

https://github.com/user-attachments/assets/954ff869-d259-4a2d-a789-dd4192edd3a4

## Usage

Unarchive `flappy-bird.qar` with Quartus, and program it to a DE10-Lite board. Connect the board to a VGA screen for video output.

### Controls
`KEY0` - Jump & Continue  
`SW0` - Reset  
`SW9` - Pause
